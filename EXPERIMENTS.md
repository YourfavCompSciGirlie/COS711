# Experiments: Experimental Setup & Methodology

Protocol for every comparison run (so numbers are comparable across Mac and Kaggle):
* validation fold 0 of `data/folds.csv` (141 observations, 235 annotation sets)
* 20 epochs × 1000 random crops, batch 8, AdamW lr 3e-4, wd 1e-4, 1 warm-up epoch then cosine decay
* checkpoint selected by validation PQ (threshold 0.5, min area 100), then post-processing tuned on the
  saved out-of-fold probabilities (`tune_post`). Both PQ values are reported.
* one change per experiment relative to the baseline (E01)

| ID | Question | Change vs E01 | Motivated by (EDA) |
|---|---|---|---|
| E01 | Baseline | U-Net, ResNet-34 (ImageNet), disk at 1024² (scale 0.5), 512² crops, BCE+Dice, separate labels, full aug | — |
| E02 | Does full resolution help thin filaments? | `--scale 1.0` (crops at native 2048² resolution) | median width ≈ 8 px, ⅓ < 8 px |
| E03 | How much does downsampling hurt? | `--scale 0.25` (disk at 512²) | same |
| E04 | Imbalance-aware loss | `--loss focal:1,tversky:1` | filaments ≈ 0.5 % of pixels |
| E05 | Annotator consensus labels | `--label-mode soft` | expert PQ ≈ 0.34, noisy instances |
| E06 | Do augmentations matter? | `--no-rotate --no-photometric` | site-dependent haze/blur |
| E07 | Does ImageNet pre-training help? | `--weights none` | 707 training images only |
| E08 | Architecture | `--arch unetplusplus` | — |
| E09 | Encoder | `--encoder efficientnet-b3` (or `mit_b2` SegFormer) | — |
| E10 | Loss focus on positives | `--pos-frac 0.4` vs 0.7 | imbalance |

Connectivity losses (clDice), instance separation and compression are the Segmentation Enhancement
work. The final configuration is trained on all 5 folds (and several seeds) for the Results section.

Added after the first runs: E01S1/E01S2 (seeds 1, 2: run-to-run noise), E11 lr 1e-4, E12 lr 1e-3,
E13 40 epochs.

**Conclusions**
* Run-to-run noise (baseline, 3 seeds) is ±0.010 PQ. Nine of twelve changes fall inside it: at this
  budget the network is not the bottleneck. Instance extraction is: across all runs, one-to-many
  errors (one filament split into pieces) outnumber many-to-one errors 4–5×.
* Significant: input resolution (512² loses 0.036, as predicted by the filament-width analysis),
  ImageNet pre-training (+0.018), learning rate (1e-4 under-trains in 20 epochs).
* Post-processing tuning adds ≈ +0.03 PQ in every run; min instance area 400 px is always optimal,
  the best threshold varies (0.4–0.8) with the loss/calibration.
* EfficientNet-B3 matches the baseline with 54 % of the parameters (51 MB vs 93 MB): input for the
  compression work.
* Kaggle public LB of the baseline (fold-0 model): 0.32 vs local 0.389 (≈ 0.07 local→public gap).

**Decision (2026-10-29):** final model = E01 baseline (U-Net ResNet-34, 1024² disk, BCE+Dice,
augmentation, lr 3e-4, 20 × 1000 crops), trained on all 5 folds (`runs/e01_baseline/fold0..4`) →
5-fold mean ± std for Results, 5-model ensemble for the submission, OOF probabilities on all 707
training observations for post-processing/enhancement work.
